bsj-pi-release-agreement.pdf
    The PI release agreement students send to their faculty sponsor.
    Linked from the "Have your PI sign the release agreement" step.

To replace it with a newer version, save the new PDF over the old one using
exactly the same filename, then run ./scripts/deploy.sh. Nothing else to change.

Note: older copies of this form in the site archive route to
research.bsj@gmail.com, which is no longer the address used. Make sure any
version published here says bsj.berkeley@gmail.com.
